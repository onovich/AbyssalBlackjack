# Manual Regression Checklist

这份清单用于每次调整规则、时序或 UI 结构后做一轮快速人工复核。

## 使用方式

- 本地启动项目后，从头开一局，按下面顺序验证。
- 每项只要求确认当前行为是否仍符合现有 Web 版，不要求额外优化。
- 如果某一项失败，优先记录“进入条件、实际表现、预期表现、是否可稳定复现”。

## 1. 启动与首屏

- [ ] 首屏能正常加载，没有空白页或控制台报错。
- [ ] 标题、四条说明文案、开始按钮都能正常显示。
- [ ] 点击“跃入深渊”后能稳定进入第一场战斗。
- [ ] 顶部状态栏正确显示生命、金币、层数。

## 2. 常规对局流

- [ ] 玩家点击抽牌后，手牌、牌库数量、技能充能都会更新。
- [ ] 玩家点击停牌后，庄家会继续按规则行动。
- [ ] 双方都停牌后，能正常显示胜负文案并进入下一阶段。
- [ ] 爆牌时会直接结算，并正确扣除生命。

## 3. 同花效果

- [ ] 出现同花时，点数旁会显示“同花”标记。
- [ ] 点击同花标记上的 ? 按钮，可以看到效果说明。
- [ ] 再次点击关闭按钮后，说明浮层会收起。
- [ ] 同花说明不会挡住主要操作按钮到无法继续游戏。

## 4. Joker 流程

- [ ] 抽到小丑牌后，会进入小丑投掷界面。
- [ ] 连续投掷时，显示的骰子数量会递增。
- [ ] 主动停止投掷后，流程会正确回到正常对局。
- [ ] 小丑爆掉后，会显示销毁文案、移除该牌，并继续后续结算或回合推进。
- [ ] 如果小丑刚好把点数推到 21，会按现有规则直接进入胜利流程。

## 5. 技能流程

- [ ] 充能不足时，定向塞牌和卡牌重抽按钮保持不可用。
- [ ] 充能足够时，点击定向塞牌后能进入选牌态，再次点击可取消。
- [ ] 选择一张牌执行塞牌后，该牌会进入敌方手牌，并正确触发后续结算或回合切换。
- [ ] 充能足够时，点击卡牌重抽后能进入选牌态，再次点击可取消。
- [ ] 执行重抽后，原牌会离手，新牌会替换到原位置；若抽到小丑，会立即进入小丑流程。

## 6. 庄家回合与边界条件

- [ ] 庄家常规抽牌、停牌、思考文案都能正常出现。
- [ ] 庄家抽到剪刀牌时，前一张牌会按现有规则被斩碎。
- [ ] 庄家无牌可抽时，会显示“无牌可抽，被迫停牌”。
- [ ] 当玩家已停牌且庄家无牌可抽时，会自动进入结算，不会卡死在战斗界面。

## 7. 结算后推进

- [ ] 普通胜利后进入附魔界面，并出现两种附魔选项。
- [ ] 跳过附魔后会进入商店。
- [ ] 平局或失败后会进入商店，并正确结算金币。
- [ ] 商店中购买、治疗、删牌、进入下一层都能正常工作。
- [ ] 治疗在生命满值时保持禁用。

## 8. 整局收口

- [ ] 生命归零时会进入失败结算界面。
- [ ] 在最终层获胜时会进入通关界面。
- [ ] 结束界面的统计信息与本局过程一致。
- [ ] 点击“再来一局”后，游戏会重置到可正常开局的状态。
