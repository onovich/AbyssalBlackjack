# AbyssalBlackjack

[简体中文](README.zh-CN.md)

A single-player blackjack roguelike built around deck manipulation, jokers, and enchanted cards.

![AbyssalBlackjack cover](docs/cover.png)

**[Live version](https://game.onovich.com/AbyssalBlackjack/)**

## What it includes

- Blackjack-based deckbuilding.
- Jokers, enchantments, and redraw decisions.
- Browser build with automated checks.

## Getting started

Install dependencies and start the local version:

```bash
npm install
npm run dev
```

The repository also provides `npm run build`、`npm run test`.

## Repository map

- `src/` — Application and library source.
- `docs/` — Project documentation and design notes.
- `origin/` — Original prototype and design material.
- `.github` — Automation and GitHub Pages workflows.
